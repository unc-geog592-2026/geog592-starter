# Data

Shared datasets used across multiple exercises and assignments.

Use assignment-specific data inside the relevant assignment folder when possible.

## GitHub file-size limits

GitHub is not intended for storing large GIS datasets.

- Files larger than **50 MiB** generate a warning.
- Files larger than **100 MiB** cannot be stored in a regular GitHub repository.
- Files uploaded through the GitHub website are limited to **25 MiB per file**.

For large datasets, use the storage location specified for the assignment rather than adding the files directly to the repository.
